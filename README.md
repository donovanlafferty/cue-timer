# Cue Timer

A lightweight, zero-dependency, keyboard-first interval and cue timer built by **Donovan Lafferty** in a single HTML file.

## Features
- **Drift-free timing:** Anchors to `performance.now()` instead of trusting `setInterval` ticks.
- **No audio assets:** Generates a clean two-tone completion chime on the fly using the browser's native Web Audio API.
- **Keyboard controls:** `Space` to start/pause, `R` to reset, `1`/`2`/`3` for 5m, 15m, and 25m presets.
- **Zero build step:** Open `index.html` locally in any browser.
